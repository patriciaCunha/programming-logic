# JavaScript Programming Logic — Alura

This repository contains exercises and projects developed while studying programming logic with JavaScript through Alura courses.

## Project

**Secret Number Game**

A simple interactive game in which the player tries to guess a secret number between 1 and 10.

### Features

* Displays a welcome message.
* Asks the player to guess a number.
* Compares the guess with the secret number.
* Provides feedback when the guess is too high or too low.

## Technologies

* HTML
* CSS
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Follow the instructions displayed by the game.

## Learning Goals

* Practice JavaScript variables.
* Use `prompt()` and `alert()`.
* Work with conditional statements (`if` and `else`).
* Compare values and provide feedback to the player.
